Atajos de teclado disponibles

  • F1: Mostrar/Ocultar este menú de atajos
  • ⌨️ (en el editor): Mostrar/Ocultar la barra de símbolos para programar
  • F2: Ocultar etiquetas de usuarios/profesores
  • F3: Mazimizar/Minimizar editor de codigo
  • F4: Restaurar plantilla inicial
  • F5: Intercambiar entre editor de código y pizarra
  • F6: Generar Prototipos
  • F7: Enviar prueba de validacion
  • F8: Maximizar/Minimizar Salida
  • F9: Ejecutar código
  • F10: Ver ejercicios por encima / Restaurar editor o pizarra
  • F11: Cambiar plantilla
  • Shift + F11: Pantalla completa del navegador
  • F12: Busca siguiente error de compilacion
  • Ctrl + Alt + ↑ o Alt + T: Mover línea arriba
  • Ctrl + Alt + ↓ o Alt + R: Mover línea abajo
  • Ctrl + Shift + ↑ o Alt + V: Duplicar línea arriba
  • Ctrl + Shift + ↓ o Alt + C: Duplicar línea abajo
  • Ctrl + D: Seleccionar varias lineas en simultaneoasd (multi-cursor)
  • Ctrl + F: Buscar y reemplazar (en todo el código, o solo en el fragmento seleccionado)
  • Ctrl + H: Restaurar desde el historial del servidor: 1.ª vez la versión más reciente del archivo actual, cada pulsación siguiente una versión más antigua (vuelve a empezar al llegar a la más vieja)
  • Ctrl + S: Descargar código (.cpp) o pizarra (PNG) si está abierta
  • Pizarra (con la pizarra abierta):
  • Ctrl + 1: Lápiz · Ctrl + 2: Goma · Ctrl + 3: Mano (pan)
  • Ctrl + 4: Puntero · Ctrl + 5: Selección · Ctrl + 6: Línea
  • Ctrl + 7: Rectángulo · Ctrl + 8: Círculo
  • + / −: Grosor · Ctrl + Z / Y: Deshacer / Rehacer
